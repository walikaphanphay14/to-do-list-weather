อยากจะทำให้คนอื่นเห็นงานที่เราบันทึกไว้ เนื่องจากอันนี้ใช้ local storage ทำให้สามารถเก็บได้แค่เครื่องที่เป็นคนบันทึก
ไม่ได้ใช้ git ตั้งแต่แรกพึ่งมาอัพลง git ตอนทำงานเสร็จ หากมีครั้งหน้าก็จะ commit ทีละขั้น เนื่องจากไม่เคยใช้ เลยทำให้ใช้เวลากับการทำตรงนี้ค่อนข้างมาก แต่ก็พร้อมศึกษาเรียนรู้เพิ่มเติม
มีส่วนที่อยากแก้คือตรงรายละเอียดงาน อยากให้เป็นกดบันทึกแล้วขึ้นรายละเอียดของงานในหน้าแรกด้วย
